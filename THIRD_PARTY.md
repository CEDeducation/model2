# Third-party and reference notes

OpenLab v1.0 runtime dependencies are Next.js, React and React DOM. The application UI and molecular visualization are original OpenLab code; no Benchling source code, images, icons or proprietary assets are included.

The visual direction uses common modern scientific-software patterns: persistent navigation, dense but readable scientific workspaces, contextual inspectors, linked records and direct manipulation of sequence maps.

The bundled pUC19 files under `public/reference/` are included only as reference/import-test data. Review source/provenance requirements before redistributing reference sequence records in another product context.
